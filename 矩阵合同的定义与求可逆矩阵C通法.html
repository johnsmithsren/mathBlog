线性代数核心考点：矩阵合同的定义、几何背景与求可逆矩阵 CCC 的全套通法 #

一、什么是“合同”？（一文搞懂） #

1. 严格数学定义 #

[!IMPORTANT] 定义（矩阵合同）： 设 A,BA, BA,B 是同阶方阵（考研中默认都是实对称矩阵），若存在一个可逆矩阵 CCC，使得：

CTAC=BC^\mathrm{T} A C = BCTAC=B

则称矩阵 AAA 与 BBB 合同，记作 A≃BA \simeq BA≃B。

2. 通俗理解：合同是“二次型”在坐标变换下的影子！ #

为什么会冒出 CTACC^\mathrm{T} A CCTAC 这种形式？它来自二次型的变量替换：

  1. 设一个二次型用矩阵表示为：

f(x)=xTAxf(\boldsymbol{x}) = \boldsymbol{x}^\mathrm{T} A \boldsymbol{x}f(x)=xTAx

  1. 现在我们做一次可逆线性替换（换一组坐标系），令：

x=Cy(C 可逆)\boldsymbol{x} = C \boldsymbol{y} \quad (C \text{ 可逆})x=Cy(C 可逆)

  1. 把 x=Cy\boldsymbol{x} = C\boldsymbol{y}x=Cy 代入原来的二次型中：

f=(Cy)TA(Cy)=yT(CTAC)yf = (C\boldsymbol{y})^\mathrm{T} A (C\boldsymbol{y}) = \boldsymbol{y}^\mathrm{T} (C^\mathrm{T} A C) \boldsymbol{y}f=(Cy)TA(Cy)=yT(CTAC)y

  1. 令新矩阵为 B=CTACB = C^\mathrm{T} A CB=CTAC，此时二次型就变成了：

f=yTByf = \boldsymbol{y}^\mathrm{T} B \boldsymbol{y}f=yTBy

本质一句话： 合同矩阵就是“同一个二次型在不同坐标系下的两个度量矩阵”！
只要是通过可逆线性替换从矩阵 AAA 变过来的矩阵 BBB，它们俩之间就是合同关系。

3. 合同的核心判定准则（考研选择题秒杀） #

[!TIP] 实对称矩阵合同的充要条件（惯性定理）： 两个同阶实对称矩阵 AAA 与 BBB 合同   ⟺  \iff⟺ 它们具有相同的正惯性指数 ppp 和负惯性指数 qqq。 （通俗说：正特征值的个数相同，负特征值的个数相同，0 特征值的个数相同）。

【方法二：初等行、列同步变换法（考场最快、最不易错的机械化大招）】 #

[!TIP] 初等变换法求合同变换矩阵原理：

  • 对 AAA 做一次初等行变换，相当于左乘 PTP^\mathrm{T}PT；
  • 紧接着对它做一次相同的初等列变换，相当于右乘 PPP；
  • 构造分块矩阵 [AE]\begin{bmatrix} A \\ E \end{bmatrix}[AE​]：
    • 对 AAA 和下面的 EEE 同时做相同的列变换（对 AAA 右乘 CCC，对 EEE 也右乘 CCC）；
    • 仅对上半部分的 AAA 做行变换（左乘 CTC^\mathrm{T}CT）；
    • 当上半部分变成 BBB 时，下半部分的 EEE 就自动变成了所求的可逆矩阵 CCC！
