题 9：幂等矩阵 A2=AA^2 = AA2=A 的特征值与相似判定 #

【题目】

【规范解题步骤】

  1. 第 (1) 问：求 AAA 的特征值： 设 λ\lambdaλ 为 AAA 的特征值，xxx 为对应的非零特征向量，则 Ax=λxAx = \lambda xAx=λx。 两边左乘 AAA：

A2x=A(λx)=λ(Ax)=λ2xA^2 x = A(\lambda x) = \lambda (Ax) = \lambda^2 xA2x=A(λx)=λ(Ax)=λ2x

由 A2=AA^2 = AA2=A 得：A2x=Ax=λxA^2 x = Ax = \lambda xA2x=Ax=λx。由此：

λ2x=λx  ⟹  (λ2−λ)x=0\lambda^2 x = \lambda x \implies (\lambda^2 - \lambda) x = 0λ2x=λx⟹(λ2−λ)x=0

因 x≠0x \ne 0x=0，必有 λ2−λ=0  ⟹  λ=0\lambda^2 - \lambda = 0 \implies \lambda = 0λ2−λ=0⟹λ=0 或 λ=1\lambda = 1λ=1。 2. 结合秩确定特征值重数： 矩阵阶数 n=3n = 3n=3。齐次方程组 Ax=0Ax = 0Ax=0 的基础解系包含向量个数为：

n−r(A)=3−2=1n - \mathrm{r}(A) = 3 - 2 = 1n−r(A)=3−2=1

这说明属于特征值 λ=0\lambda = 0λ=0 的线性无关特征向量有 1 个（代数重数与几何重数均为 1）。
其余特征值必全为 1，故 λ=1\lambda = 1λ=1 是二重特征根。 全部特征值为：λ1=1,λ2=1,λ3=0\lambda_1 = 1, \quad \lambda_2 = 1, \quad \lambda_3 = 0λ1​=1,λ2​=1,λ3​=0。 3. 第 (2) 问：证明必可对角化： 对于二重特征值 λ=1\lambda = 1λ=1，考虑方程 (E−A)x=0(E - A)x = 0(E−A)x=0。 因为 A2=A  ⟹  A(E−A)=OA^2 = A \implies A(E - A) = OA2=A⟹A(E−A)=O。 根据矩阵秩的性质：r(A)+r(E−A)≤3\mathrm{r}(A) + \mathrm{r}(E - A) \le 3r(A)+r(E−A)≤3。 代入 r(A)=2\mathrm{r}(A) = 2r(A)=2 得：r(E−A)≤3−2=1\mathrm{r}(E - A) \le 3 - 2 = 1r(E−A)≤3−2=1。又 A≠EA \ne EA=E，故 r(E−A)=1\mathrm{r}(E - A) = 1r(E−A)=1。 所以属于特征值 λ=1\lambda = 1λ=1 的线性无关特征向量个数为：

n−r(E−A)=3−1=2n - \mathrm{r}(E - A) = 3 - 1 = 2n−r(E−A)=3−1=2

几何重数等于代数重数（均为 2）。 【结论】 AAA 共有 3 个线性无关的特征向量，必可相似对角化，且相似于 diag(1,1,0)\mathrm{diag}(1, 1, 0)diag(1,1,0)。
