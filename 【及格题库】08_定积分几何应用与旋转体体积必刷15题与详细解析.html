【及格题库】08 定积分几何应用与旋转体体积必刷15题与详细解析 #

命题规律与提分策略： 定积分几何应用（平面图形面积与旋转体体积）是数二解答题（第 17 或 18 题，10~12 分）或填空题（5 分）的超级钉子户！ 这里的核心得分逻辑是：

  1. 两套公式背得滚瓜烂熟（绕 xxx 轴圆盘法 vs 绕 yyy 轴柱壳法）；
  2. 画出草图找准上下限交点；
  3. 计算绝不漏乘系数 π\piπ 或 2π2\pi2π。

【第 1 题】抛物线与直线相交面积（最基础送分模版） #

【题目】 求抛物线 y=x2y = x^2y=x2 与直线 y=2xy = 2xy=2x 所围成平面图形的面积 SSS。

    1. 联立方程求交点：

x2=2x  ⟹  x(x−2)=0  ⟹  x1=0,x2=2x^2 = 2x \implies x(x - 2) = 0 \implies x_1 = 0, x_2 = 2x2=2x⟹x(x−2)=0⟹x1​=0,x2​=2

  1. 判断上下曲线位置： 在区间 [0,2][0, 2][0,2] 上，取 x=1x = 1x=1 验算，y直=2>y抛=1y_{\text{直}} = 2 > y_{\text{抛}} = 1y直​=2>y抛​=1，故上方曲线为 y=2xy = 2xy=2x，下方曲线为 y=x2y = x^2y=x2。
  2. 套公式积分：

S=∫02(2x−x2) dx=(x2−13x3)∣02=(4−83)−0=43S = \int_0^2 (2x - x^2)\,\mathrm{d}x = \left.\left(x^2 - \frac{1}{3}x^3\right)\right|_0^2 = \left(4 - \frac{8}{3}\right) - 0 = \frac{4}{3}S=∫02​(2x−x2)dx=(x2−31​x3)​02​=(4−38​)−0=34​
