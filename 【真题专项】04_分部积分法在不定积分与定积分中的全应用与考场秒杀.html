【真题专项】04 分部积分法在不定积分与定积分中的全应用与考场秒杀 #

一、 分部积分法核心公式与选 uuu 黄金铁律 #

1. 核心公式对照 #

  • 不定积分分部公式：

∫u dv=uv−∫v du\int u\,\mathrm{d}v = u v - \int v\,\mathrm{d}u∫udv=uv−∫vdu

  • 定积分分部公式：

∫abu dv=[uv]ab−∫abv du\int_a^b u\,\mathrm{d}v = \Big[ u v \Big]_a^b - \int_a^b v\,\mathrm{d}u∫ab​udv=[uv]ab​−∫ab​vdu

本质：乘积导数法则 (uv)′=u′v+uv′(uv)' = u'v + uv'(uv)′=u′v+uv′ 两边积分的逆向变形。

2. 谁选作 uuu？谁选作 dv\mathrm{d}vdv？——“反对幂指三”铁律 #

分部积分的核心灵魂，在于把难积的 ∫u dv\int u\,\mathrm{d}v∫udv 转化为容易积的 ∫v du\int v\,\mathrm{d}u∫vdu！
因此，选择 uuu 和 dv\mathrm{d}vdv 必须遵循考研天下第一口诀：

🏆 核心选择口诀：【反】 →\to→ 【对】 →\to→ 【幂】 →\to→ 【指】 →\to→ 【三】 #

简称 对应函数类别 典型代表 选作 uuu 还是 dv\mathrm{d}vdv？ 核心逻辑
反 反三角函数 arcsin⁡x,arctan⁡x\arcsin x, \arctan xarcsinx,arctanx ⭐ 最优先选作 uuu 本身几乎积不出原函数，求导后变成简单的无理或有理分式！
对 对数函数 ln⁡x,log⁡ax\ln x, \log_a xlnx,loga​x ⭐ 优先选作 uuu 不好积分，求导后变成 1x\frac{1}{x}x1​，瞬间降解为代数多项式！
幂 幂函数/多项式 x,x2,xnx, x^2, x^nx,x2,xn 居中调节器 遇到“指、三”时作 uuu（求导降幂）；遇到“反、对”时作 dv\mathrm{d}vdv。
指 指数函数 ex,axe^x, a^xex,ax ⭐ 优先选作 dv\mathrm{d}vdv 极易积分，反复积分形式不变（原函数还是自身乘常数）。
三 三角函数 sin⁡x,cos⁡x\sin x, \cos xsinx,cosx ⭐ 优先选作 dv\mathrm{d}vdv 极易积分，sin⁡x,cos⁡x\sin x, \cos xsinx,cosx 积分只是正负号与三角名互换。

💡 考场判定准则： 两个函数相乘，排在前面的优先选为 uuu（求导降解）；排在后面的优先并入 dv\mathrm{d}vdv（凑微分积出 vvv）！

二、 考场降维神器：表格分部积分法（Tabular Integration） #

当遇到多项式 P(x)P(x)P(x) 乘以 eaxe^{ax}eax、sin⁡ax\sin axsinax 或 cos⁡ax\cos axcosax 时，如果多项式是二次或三次（如 x2,x3x^2, x^3x2,x3），传统做法需要分部积分 2~3 次，步骤极其冗长，正负号极其容易写错！

考场上直接使用表格法（又称划线法），15 秒直出答案：

1. 表格法三步绘制指南 #

以 ∫x3e2x dx\int x^3 e^{2x} \, \mathrm{d}x∫x3e2xdx 为例：

  1. 左列放多项式（求导列 uuu）：逐次向下求导，一直求导到 000 为止；
  2. 右列放易积函数（积分列 v′v'v′）：逐次向下求不定积分（不需要写常数 CCC）；
  3. 连线配符号：
    • 从左列第 1 个数开始，斜向右下方连线到右列第 2 个数；
    • 符号从第 1 条线开始按 +++, −-−, +++, −-− 依次交替交织；
    • 沿斜线相乘求和，最后加上 +C+ C+C 即可！

三、 分部积分法在【不定积分】中的五大必考模型 #

模型 1：多项式 ×\times× 指数/三角（降幂型） #

【典例 1】求 ∫(x2+1)cos⁡x dx\int (x^2 + 1)\cos x\,\mathrm{d}x∫(x2+1)cosxdx

  • 传统分部法：

∫(x2+1)cos⁡x dx=∫(x2+1) d(sin⁡x)=(x2+1)sin⁡x−∫sin⁡x⋅(2x) dx\int (x^2 + 1)\cos x\,\mathrm{d}x = \int (x^2 + 1)\,\mathrm{d}(\sin x) = (x^2+1)\sin x - \int \sin x \cdot (2x)\,\mathrm{d}x∫(x2+1)cosxdx=∫(x2+1)d(sinx)=(x2+1)sinx−∫sinx⋅(2x)dx

后项继续分部：

∫2xsin⁡x dx=∫2x d(−cos⁡x)=−2xcos⁡x−∫(−cos⁡x)⋅2 dx=−2xcos⁡x+2sin⁡x\int 2x \sin x\,\mathrm{d}x = \int 2x\,\mathrm{d}(-\cos x) = -2x\cos x - \int (-\cos x)\cdot 2\,\mathrm{d}x = -2x\cos x + 2\sin x∫2xsinxdx=∫2xd(−cosx)=−2xcosx−∫(−cosx)⋅2dx=−2xcosx+2sinx

合并带入：

=(x2+1)sin⁡x−(−2xcos⁡x+2sin⁡x)+C=(x2−1)sin⁡x+2xcos⁡x+C= (x^2+1)\sin x - (-2x\cos x + 2\sin x) + C = (x^2 - 1)\sin x + 2x\cos x + C=(x2+1)sinx−(−2xcosx+2sinx)+C=(x2−1)sinx+2xcosx+C

  • 表格法秒算：
    • 求导列：x2+1→2x→2→0x^2+1 \to 2x \to 2 \to 0x2+1→2x→2→0
    • 积分列：cos⁡x→sin⁡x→−cos⁡x→−sin⁡x\cos x \to \sin x \to -\cos x \to -\sin xcosx→sinx→−cosx→−sinx
    • 斜向相乘： +(x2+1)(sin⁡x)−(2x)(−cos⁡x)+(2)(−sin⁡x)+C=(x2−1)sin⁡x+2xcos⁡x+C+(x^2+1)(\sin x) - (2x)(-\cos x) + (2)(-\sin x) + C = (x^2-1)\sin x + 2x\cos x + C+(x2+1)(sinx)−(2x)(−cosx)+(2)(−sinx)+C=(x2−1)sinx+2xcosx+C！

模型 2：多项式 ×\times× 反三角/对数（消灭反三角/对数型） #

【战术关键】

按照“反对幂指三”，反三角和对数排在幂函数前面，必须设为 uuu，把多项式凑入微分 dv\mathrm{d}vdv 中！

模型 3：单一反三角与对数函数（“隐式 1”技巧） #

【战术关键】

形如 ∫ln⁡x dx,∫arcsin⁡x dx,∫arctan⁡x dx\int \ln x\,\mathrm{d}x, \int \arcsin x\,\mathrm{d}x, \int \arctan x\,\mathrm{d}x∫lnxdx,∫arcsinxdx,∫arctanxdx。

模型 4：指数 ×\times× 三角（循环回归型与公式解） #

【战术关键】

对 eaxsin⁡bxe^{ax}\sin bxeaxsinbx 或 eaxcos⁡bxe^{ax}\cos bxeaxcosbx，求导和积分都不会降阶。连续分部积分两次后，原积分必然再次出现，通过移项解方程求出！

【考研秒杀公式（直接背诵）】

∫eaxsin⁡bx dx=eaxa2+b2(asin⁡bx−bcos⁡bx)+C\int e^{ax} \sin bx\,\mathrm{d}x = \frac{e^{ax}}{a^2 + b^2} (a \sin bx - b \cos bx) + C∫eaxsinbxdx=a2+b2eax​(asinbx−bcosbx)+C

∫eaxcos⁡bx dx=eaxa2+b2(acos⁡bx+bsin⁡bx)+C\int e^{ax} \cos bx\,\mathrm{d}x = \frac{e^{ax}}{a^2 + b^2} (a \cos bx + b \sin bx) + C∫eaxcosbxdx=a2+b2eax​(acosbx+bsinbx)+C

记忆秘诀：分母统一是平方和 a2+b2a^2+b^2a2+b2；括号内先写原本的三角名（乘系数 aaa），后面写导数项的三角名（乘系数 bbb）。
