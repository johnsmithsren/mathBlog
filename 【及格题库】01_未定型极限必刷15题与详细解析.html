【及格题库】01_未定型极限必刷15题与详细解析 #

题 1：基础 0/00/00/0 型（三角函数展开） #

【题目】
求极限：

lim⁡x→0sin⁡x−xcos⁡xx3\lim_{x \to 0} \frac{\sin x - x \cos x}{x^3}x→0lim​x3sinx−xcosx​

【命题预测与思路】
分母为 x3x^3x3，分子中的 sin⁡x\sin xsinx 和 cos⁡x\cos xcosx 必须展开到 x3x^3x3 项（cos⁡x\cos xcosx 本身只需展开到 x2x^2x2，乘外面的 xxx 后正好是 x3x^3x3）。

【规范解题步骤】
当 x→0x \to 0x→0 时，利用泰勒公式展开：

sin⁡x=x−x36+o(x3)\sin x = x - \frac{x^3}{6} + o(x^3)sinx=x−6x3​+o(x3)

cos⁡x=1−x22+o(x2)  ⟹  xcos⁡x=x−x32+o(x3)\cos x = 1 - \frac{x^2}{2} + o(x^2) \implies x \cos x = x - \frac{x^3}{2} + o(x^3)cosx=1−2x2​+o(x2)⟹xcosx=x−2x3​+o(x3)

代入原式分子：

sin⁡x−xcos⁡x=(x−x36)−(x−x32)+o(x3)=(−16+12)x3+o(x3)=13x3+o(x3)\sin x - x \cos x = \left( x - \frac{x^3}{6} \right) - \left( x - \frac{x^3}{2} \right) + o(x^3) = \left( -\frac{1}{6} + \frac{1}{2} \right) x^3 + o(x^3) = \frac{1}{3} x^3 + o(x^3)sinx−xcosx=(x−6x3​)−(x−2x3​)+o(x3)=(−61​+21​)x3+o(x3)=31​x3+o(x3)

因此：

lim⁡x→0sin⁡x−xcos⁡xx3=lim⁡x→013x3+o(x3)x3=13.\lim_{x \to 0} \frac{\sin x - x \cos x}{x^3} = \lim_{x \to 0} \frac{\frac{1}{3}x^3 + o(x^3)}{x^3} = \frac{1}{3}.x→0lim​x3sinx−xcosx​=x→0lim​x331​x3+o(x3)​=31​.

题 2：指数与对数混合 0/00/00/0 型 #

【规范解题步骤】

题 4：三角差值经典必考公式模型 #

【题目】
求极限：

lim⁡x→0tan⁡x−sin⁡xx3\lim_{x \to 0} \frac{\tan x - \sin x}{x^3}x→0lim​x3tanx−sinx​

【命题预测与思路】

【规范解题步骤】
解法一（提公因式与等价代换法，速度最快）：

tan⁡x−sin⁡xx3=tan⁡x(1−cos⁡x)x3\frac{\tan x - \sin x}{x^3} = \frac{\tan x (1 - \cos x)}{x^3}x3tanx−sinx​=x3tanx(1−cosx)​

lim⁡x→0tan⁡x(1−cos⁡x)x3=lim⁡x→0x⋅(12x2)x3=12.\lim_{x \to 0} \frac{\tan x (1 - \cos x)}{x^3} = \lim_{x \to 0} \frac{x \cdot \left(\frac{1}{2} x^2\right)}{x^3} = \frac{1}{2}.x→0lim​x3tanx(1−cosx)​=x→0lim​x3x⋅(21​x2)​=21​.

考研必背结论：tan⁡x−sin⁡x∼12x3\tan x - \sin x \sim \frac{1}{2} x^3tanx−sinx∼21​x3。
