【第 2 题】绝对值函数的可导性与尖点判定（数二经典送分） #

【题目】
函数 f(x)=(x2−x)∣x2−4∣f(x) = (x^2 - x)|x^2 - 4|f(x)=(x2−x)∣x2−4∣ 的不可导点个数为（ ）。

(B) 1
(C) 2
(D) 3

  • 【及格秒杀法（单根不可导，重根必可导）】

    1. 因式分解：
      x2−x=x(x−1)x^2 - x = x(x - 1)x2−x=x(x−1)；
      ∣x2−4∣=∣(x−2)(x+2)∣=∣x−2∣⋅∣x+2∣|x^2 - 4| = |(x - 2)(x + 2)| = |x - 2| \cdot |x + 2|∣x2−4∣=∣(x−2)(x+2)∣=∣x−2∣⋅∣x+2∣。
    2. 考察绝对值内部两个零点 x=2x = 2x=2 与 x=−2x = -2x=−2：
      • 外面非绝对值部分在 x=2x = 2x=2 处的值：2(2−1)=2≠02(2 - 1) = 2 \ne 02(2−1)=2=0（单根，不可导！）；
      • 外面非绝对值部分在 x=−2x = -2x=−2 处的值：−2(−2−1)=6≠0-2(-2 - 1) = 6 \ne 0−2(−2−1)=6=0（单根，不可导！）。
    3. 故不可导点正好是 x=2x = 2x=2 和 x=−2x = -2x=−2 两个。
      直接秒选 (C)。

  • 【规范推导步骤】
    由定理：若 φ(x0)≠0\varphi(x_0) \ne 0φ(x0​)=0，则 F(x)=(x−x0)φ(x)∣x−x0∣F(x) = (x - x_0)\varphi(x)|x - x_0|F(x)=(x−x0​)φ(x)∣x−x0​∣ 在 x=x0x = x_0x=x0​ 处的左右导数分别为 φ(x0)\varphi(x_0)φ(x0​) 与 −φ(x0)-\varphi(x_0)−φ(x0​)，异号且非零，故导数不存在。本题在 x=±2x = \pm 2x=±2 处均满足此条件，左右导数不相等，不可导点共 2 个。

【第 3 题】反常积分敛散性审敛（考前必背口诀题） #

【题目】
反常积分 I=∫0+∞1xp(1+x2) dxI = \int_0^{+\infty} \frac{1}{x^p (1 + x^2)} \, \mathrm{d}xI=∫0+∞​xp(1+x2)1​dx 收敛的充要条件是（ ）。

    1. 看瑕点 x→0+x \to 0^+x→0+：此时 1+x2→11+x^2 \to 11+x2→1，被积函数主部为 1xp\frac{1}{x^p}xp1​。
      瑕积分收敛条件是指数小于 1：p<1p < 1p<1。
    2. 看无穷远 x→+∞x \to +\inftyx→+∞：此时 1+x2∼x21+x^2 \sim x^21+x2∼x2，被积函数主部为 1xp⋅x2=1xp+2\frac{1}{x^p \cdot x^2} = \frac{1}{x^{p+2}}xp⋅x21​=xp+21​。
      无穷积分收敛条件是总指数大于 1：p+2>1  ⟹  p>−1p + 2 > 1 \implies p > -1p+2>1⟹p>−1。
    3. 两端同时收敛，取交集：−1<p<1-1 < p < 1−1<p<1。

【第 4 题】渐近线条数排查（数二必出选择题） #

【题目】
曲线 y=x3+1x2−1y = \frac{x^3 + 1}{x^2 - 1}y=x2−1x3+1​ 的渐近线条数为（ ）。
(A) 1
(B) 2
(C) 3
(D) 4

  • 【规范推导步骤（四步防雷法）】
    1. 分母因式分解寻找可疑点：
      y=(x+1)(x2−x+1)(x+1)(x−1)y = \frac{(x + 1)(x^2 - x + 1)}{(x + 1)(x - 1)}y=(x+1)(x−1)(x+1)(x2−x+1)​。
    2. 排查铅直渐近线：
      • 在 x=−1x = -1x=−1 处：分子分母约去 (x+1)(x+1)(x+1)，lim⁡x→−1y=lim⁡x→−1x2−x+1x−1=1+1+1−2=−32≠∞\lim_{x\to -1} y = \lim_{x\to -1} \frac{x^2 - x + 1}{x - 1} = \frac{1+1+1}{-2} = -\frac{3}{2} \ne \inftylimx→−1​y=limx→−1​x−1x2−x+1​=−21+1+1​=−23​=∞！
        极限存在，是可去间断点，绝不是渐近线！
      • 在 x=1x = 1x=1 处：lim⁡x→1y=lim⁡x→1x2−x+1x−1=10=∞\lim_{x\to 1} y = \lim_{x\to 1} \frac{x^2 - x + 1}{x - 1} = \frac{1}{0} = \inftylimx→1​y=limx→1​x−1x2−x+1​=01​=∞。
        因此 x=1x = 1x=1 是一条铅直渐近线（计 1 条）。
    3. 排查水平与斜渐近线：
      当 x→∞x \to \inftyx→∞ 时，多项式除法：

y=x2−x+1x−1=x(x−1)+1x−1=x+1x−1y = \frac{x^2 - x + 1}{x - 1} = \frac{x(x - 1) + 1}{x - 1} = x + \frac{1}{x - 1}y=x−1x2−x+1​=x−1x(x−1)+1​=x+x−11​

 当 x→∞x \to \inftyx→∞ 时，1x−1→0\frac{1}{x-1} \to 0x−11​→0。  
 故存在一条**斜渐近线 y=xy = xy=x**（计 1 条）。  
 （两端均趋向于斜渐近线，无水平渐近线）。
  1. 汇总条数：1 条铅直（x=1x=1x=1）+ 1 条斜渐近线（y=xy=xy=x）= 共 2 条。
    【答案】 选 (B)。

【第 5 题】变限积分的奇偶性与周期性（秒杀送分） #

【题目】

(B) 偶函数且以 2 为周期

  • 【及格秒杀法（特值法 5 秒定答案）】
    取最简单的周期奇函数：令 f(x)=sin⁡(πx)f(x) = \sin(\pi x)f(x)=sin(πx)（奇函数，周期 T=2ππ=2T = \frac{2\pi}{\pi} = 2T=π2π​=2）。
    直接积分：

F(x)=∫0xsin⁡(πt) dt=[−cos⁡(πt)π]0x=1−cos⁡(πx)πF(x) = \int_0^x \sin(\pi t)\,\mathrm{d}t = \left[-\frac{\cos(\pi t)}{\pi}\right]_0^x = \frac{1 - \cos(\pi x)}{\pi}F(x)=∫0x​sin(πt)dt=[−πcos(πt)​]0x​=π1−cos(πx)​

  • cos⁡(π(−x))=cos⁡(πx)\cos(\pi(-x)) = \cos(\pi x)cos(π(−x))=cos(πx)，所以 F(x)F(x)F(x) 是偶函数；
  • cos⁡(π(x+2))=cos⁡(πx+2π)=cos⁡(πx)\cos(\pi(x+2)) = \cos(\pi x + 2\pi) = \cos(\pi x)cos(π(x+2))=cos(πx+2π)=cos(πx)，周期为 2。
    两者完全吻合，直接秒选 (B)。
  • 【规范推导】
    由定理：奇函数的变上限积分（下限为0）必为偶函数；且若周期函数在一个周期上的积分为 0（奇函数在对称区间 [−1,1][-1, 1][−1,1] 积分必为 0），则其变限积分必保持原周期。

【第 6 题】曲线凹凸性与切线几何位置关系 #

【题目】

(B) f(x)≤L(x)f(x) \le L(x)f(x)≤L(x)

    在山包上任意作一条切线，切线永远“罩在山顶上方”（切线在上，弧在下）！
    因此曲线高度始终小于等于切线高度：f(x)≤L(x)f(x) \le L(x)f(x)≤L(x)。
