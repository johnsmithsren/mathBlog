线性代数考点精讲：实对称矩阵特征向量的正交性与典型例题解析 #

核心疑问解答：为什么这里的不同特征向量正交（内积为0）？ #

1. 核心定理 #

[!IMPORTANT] 实对称矩阵的核心性质： 实对称矩阵属于不同特征值的特征向量必相互正交（即内积为 0）。

注意前提条件：

  1. 矩阵必须是实对称矩阵（AT=AA^\mathrm{T} = AAT=A）；
  2. 特征值必须互不相等（λi≠λj\lambda_i \neq \lambda_jλi​=λj​）。 普通矩阵（非对称矩阵）不同特征值的特征向量仅保证线性无关，并不一定正交！

2. 定理的严谨证明（考研常考证明题） #

已知：

  • AAA 为实对称矩阵，即 AT=AA^\mathrm{T} = AAT=A；
  • λ1,λ2\lambda_1, \lambda_2λ1​,λ2​ 为 AAA 的两个不同特征值（λ1≠λ2\lambda_1 \neq \lambda_2λ1​=λ2​）；
  • α1,α2\boldsymbol{\alpha}_1, \boldsymbol{\alpha}_2α1​,α2​ 分别是属于 λ1,λ2\lambda_1, \lambda_2λ1​,λ2​ 的特征向量，即：

Aα1=λ1α1,Aα2=λ2α2(α1,α2≠0)A\boldsymbol{\alpha}_1 = \lambda_1\boldsymbol{\alpha}_1, \quad A\boldsymbol{\alpha}_2 = \lambda_2\boldsymbol{\alpha}_2 \quad (\boldsymbol{\alpha}_1, \boldsymbol{\alpha}_2 \neq \mathbf{0})Aα1​=λ1​α1​,Aα2​=λ2​α2​(α1​,α2​=0)

证明目标： 证明 (α1,α2)=α1Tα2=0(\boldsymbol{\alpha}_1, \boldsymbol{\alpha}_2) = \boldsymbol{\alpha}_1^\mathrm{T} \boldsymbol{\alpha}_2 = 0(α1​,α2​)=α1T​α2​=0。

证明过程： 考虑标量乘积 α1TAα2\boldsymbol{\alpha}_1^\mathrm{T} A \boldsymbol{\alpha}_2α1T​Aα2​：

一方面，利用 Aα2=λ2α2A\boldsymbol{\alpha}_2 = \lambda_2\boldsymbol{\alpha}_2Aα2​=λ2​α2​：

α1TAα2=α1T(λ2α2)=λ2(α1Tα2)\boldsymbol{\alpha}_1^\mathrm{T} A \boldsymbol{\alpha}_2 = \boldsymbol{\alpha}_1^\mathrm{T} (\lambda_2 \boldsymbol{\alpha}_2) = \lambda_2 (\boldsymbol{\alpha}_1^\mathrm{T} \boldsymbol{\alpha}_2)α1T​Aα2​=α1T​(λ2​α2​)=λ2​(α1T​α2​)

另一方面，由于标量的转置等于其自身，且 AT=AA^\mathrm{T} = AAT=A：

α1TAα2=(α1TAα2)T=α2TATα1=α2TAα1\boldsymbol{\alpha}_1^\mathrm{T} A \boldsymbol{\alpha}_2 = (\boldsymbol{\alpha}_1^\mathrm{T} A \boldsymbol{\alpha}_2)^\mathrm{T} = \boldsymbol{\alpha}_2^\mathrm{T} A^\mathrm{T} \boldsymbol{\alpha}_1 = \boldsymbol{\alpha}_2^\mathrm{T} A \boldsymbol{\alpha}_1α1T​Aα2​=(α1T​Aα2​)T=α2T​ATα1​=α2T​Aα1​

将 Aα1=λ1α1A\boldsymbol{\alpha}_1 = \lambda_1\boldsymbol{\alpha}_1Aα1​=λ1​α1​ 代入：

α2T(Aα1)=α2T(λ1α1)=λ1(α2Tα1)=λ1(α1Tα2)\boldsymbol{\alpha}_2^\mathrm{T} (A \boldsymbol{\alpha}_1) = \boldsymbol{\alpha}_2^\mathrm{T} (\lambda_1 \boldsymbol{\alpha}_1) = \lambda_1 (\boldsymbol{\alpha}_2^\mathrm{T} \boldsymbol{\alpha}_1) = \lambda_1 (\boldsymbol{\alpha}_1^\mathrm{T} \boldsymbol{\alpha}_2)α2T​(Aα1​)=α2T​(λ1​α1​)=λ1​(α2T​α1​)=λ1​(α1T​α2​)

综合两式可得：

λ2(α1Tα2)=λ1(α1Tα2)  ⟹  (λ1−λ2)(α1Tα2)=0\lambda_2 (\boldsymbol{\alpha}_1^\mathrm{T} \boldsymbol{\alpha}_2) = \lambda_1 (\boldsymbol{\alpha}_1^\mathrm{T} \boldsymbol{\alpha}_2) \implies (\lambda_1 - \lambda_2)(\boldsymbol{\alpha}_1^\mathrm{T} \boldsymbol{\alpha}_2) = 0λ2​(α1T​α2​)=λ1​(α1T​α2​)⟹(λ1​−λ2​)(α1T​α2​)=0

因为已知 λ1≠λ2\lambda_1 \neq \lambda_2λ1​=λ2​（即 λ1−λ2≠0\lambda_1 - \lambda_2 \neq 0λ1​−λ2​=0），两边同除以 λ1−λ2\lambda_1 - \lambda_2λ1​−λ2​，必有：

α1Tα2=0\boldsymbol{\alpha}_1^\mathrm{T} \boldsymbol{\alpha}_2 = 0α1T​α2​=0

即特征向量 α1\boldsymbol{\alpha}_1α1​ 与 α2\boldsymbol{\alpha}_2α2​ 正交。证毕。

视频中的例题详细解析 #

【题目】 #

已知 AAA 是三阶实对称矩阵，特征值是 1,3,−21, 3, -21,3,−2。其中 α1=(1,2,−2)T,α2=(4,−1,a)T\boldsymbol{\alpha}_1 = (1, 2, -2)^\mathrm{T}, \boldsymbol{\alpha}_2 = (4, -1, a)^\mathrm{T}α1​=(1,2,−2)T,α2​=(4,−1,a)T 分别是属于特征值 λ=1\lambda = 1λ=1 与 λ=3\lambda = 3λ=3 的特征向量，那么矩阵 AAA 属于特征值 λ=−2\lambda = -2λ=−2 的特征向量是 ________。

【详细解答过程】 #

第一步：求参数 aaa 的值

因为 AAA 为实对称矩阵，且特征值 λ1=1≠λ2=3\lambda_1 = 1 \neq \lambda_2 = 3λ1​=1=λ2​=3： 所以 α1\boldsymbol{\alpha}_1α1​ 与 α2\boldsymbol{\alpha}_2α2​ 相互正交，即内积为 0：

(α1,α2)=α1Tα2=1×4+2×(−1)+(−2)×a=0(\boldsymbol{\alpha}_1, \boldsymbol{\alpha}_2) = \boldsymbol{\alpha}_1^\mathrm{T} \boldsymbol{\alpha}_2 = 1 \times 4 + 2 \times (-1) + (-2) \times a = 0(α1​,α2​)=α1T​α2​=1×4+2×(−1)+(−2)×a=0

4−2−2a=0  ⟹  2−2a=0  ⟹  a=14 - 2 - 2a = 0 \implies 2 - 2a = 0 \implies a = 14−2−2a=0⟹2−2a=0⟹a=1

因此：

α2=(4,−1,1)T\boldsymbol{\alpha}_2 = (4, -1, 1)^\mathrm{T}α2​=(4,−1,1)T

第二步：求属于 λ=−2\lambda = -2λ=−2 的特征向量 α3\boldsymbol{\alpha}_3α3​

设属于 λ=−2\lambda = -2λ=−2 的特征向量为 α3=(x1,x2,x3)T≠0\boldsymbol{\alpha}_3 = (x_1, x_2, x_3)^\mathrm{T} \neq \mathbf{0}α3​=(x1​,x2​,x3​)T=0。

因为 −2≠1-2 \neq 1−2=1 且 −2≠3-2 \neq 3−2=3，根据实对称矩阵性质，α3\boldsymbol{\alpha}_3α3​ 必然与 α1,α2\boldsymbol{\alpha}_1, \boldsymbol{\alpha}_2α1​,α2​ 都正交：

  1. α1Tα3=0  ⟹  x1+2x2−2x3=0\boldsymbol{\alpha}_1^\mathrm{T} \boldsymbol{\alpha}_3 = 0 \implies x_1 + 2x_2 - 2x_3 = 0α1T​α3​=0⟹x1​+2x2​−2x3​=0
  2. α2Tα3=0  ⟹  4x1−x2+x3=0\boldsymbol{\alpha}_2^\mathrm{T} \boldsymbol{\alpha}_3 = 0 \implies 4x_1 - x_2 + x_3 = 0α2T​α3​=0⟹4x1​−x2​+x3​=0

解该齐次线性方程组：

{x1+2x2−2x3=0(1)4x1−x2+x3=0(2)\begin{cases} x_1 + 2x_2 - 2x_3 = 0 & \text{(1)} \\ 4x_1 - x_2 + x_3 = 0 & \text{(2)} \end{cases}{x1​+2x2​−2x3​=04x1​−x2​+x3​=0​(1)(2)​

由方程 ② 可得：

x3=x2−4x1x_3 = x_2 - 4x_1x3​=x2​−4x1​

代入方程 ①：

x1+2x2−2(x2−4x1)=0x_1 + 2x_2 - 2(x_2 - 4x_1) = 0x1​+2x2​−2(x2​−4x1​)=0

x1+2x2−2x2+8x1=0  ⟹  9x1=0  ⟹  x1=0x_1 + 2x_2 - 2x_2 + 8x_1 = 0 \implies 9x_1 = 0 \implies x_1 = 0x1​+2x2​−2x2​+8x1​=0⟹9x1​=0⟹x1​=0

将 x1=0x_1 = 0x1​=0 代回 x3=x2−4x1x_3 = x_2 - 4x_1x3​=x2​−4x1​ 得：

x3=x2x_3 = x_2x3​=x2​

令自由未知量 x2=1x_2 = 1x2​=1，则 x3=1x_3 = 1x3​=1。 基础解系为：

ξ=(0,1,1)T\boldsymbol{\xi} = (0, 1, 1)^\mathrm{T}ξ=(0,1,1)T

[!NOTE] 法向向量叉乘技巧（快速求两向量同时正交的向量）： 在三维空间中，同时与 α1,α2\boldsymbol{\alpha}_1, \boldsymbol{\alpha}_2α1​,α2​ 正交的向量可直接用**外积（叉乘）**快速求出：

化简可取基础向量为 (0,1,1)T(0, 1, 1)^\mathrm{T}(0,1,1)T。

第三步：规范书写答案

特征向量不能写成零向量，且非零倍数均为特征向量：

k(0,1,1)T(k≠0)k(0, 1, 1)^\mathrm{T} \quad (k \neq 0)k(0,1,1)T(k=0)

（若填空题直接填某个具体非零向量，通常填 (0,1,1)T(0, 1, 1)^\mathrm{T}(0,1,1)T 即可）。
