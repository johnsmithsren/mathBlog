【第 1 题】标准多项式极大值计算 #

【题目】 函数 f(x)=x3−3x+2f(x) = x^3 - 3x + 2f(x)=x3−3x+2 的极大值为 _____。

  • 【秒杀步骤】
    1. 求导找驻点：f′(x)=3x2−3=3(x−1)(x+1)=0  ⟹  x=±1f'(x) = 3x^2 - 3 = 3(x - 1)(x + 1) = 0 \implies x = \pm 1f′(x)=3x2−3=3(x−1)(x+1)=0⟹x=±1。
    2. 看二阶导判极大值：f′′(x)=6xf''(x) = 6xf′′(x)=6x。
      • 当 x=−1x = -1x=−1 时，f′′(−1)=−6<0f''(-1) = -6 < 0f′′(−1)=−6<0，取得极大值！
    3. 代入算值：f(−1)=(−1)3−3(−1)+2=−1+3+2=4f(-1) = (-1)^3 - 3(-1) + 2 = -1 + 3 + 2 = 4f(−1)=(−1)3−3(−1)+2=−1+3+2=4。
    4. 【答案】 填 4。

【第 2 题】指数复合函数极值 #

【题目】 函数 f(x)=xe−xf(x) = x e^{-x}f(x)=xe−x 的极值点为 x=x =x= _____，极值为 _____。

  • 【秒杀步骤】
    1. 求导：f′(x)=1⋅e−x+x(−e−x)=(1−x)e−x=0f'(x) = 1\cdot e^{-x} + x(-e^{-x}) = (1 - x)e^{-x} = 0f′(x)=1⋅e−x+x(−e−x)=(1−x)e−x=0。
    2. 因 e−x>0e^{-x} > 0e−x>0 恒成立，唯一驻点为 x=1x = 1x=1。
    3. 导数在 x=1x = 1x=1 左侧为正、右侧为负（由增变减），故 x=1x = 1x=1 为极大值点。
    4. 极大值为 f(1)=1⋅e−1=1ef(1) = 1 \cdot e^{-1} = \frac{1}{e}f(1)=1⋅e−1=e1​。
    5. 【答案】 极值点为 1，极大值为 \frac{1}{e}。

【第 3 题】闭区间最值速算（三个数挑大小） #

【题目】 函数 f(x)=2x3−9x2+12xf(x) = 2x^3 - 9x^2 + 12xf(x)=2x3−9x2+12x 在区间 [0,3][0, 3][0,3] 上的最大值为 _____，最小值为 _____。

    2. 算 4 个候选数值（不用判别凹凸）：
      • 左端点：f(0)=0f(0) = 0f(0)=0
      • 驻点 1：f(1)=2−9+12=5f(1) = 2 - 9 + 12 = 5f(1)=2−9+12=5
      • 驻点 2：f(2)=2(8)−9(4)+12(2)=16−36+24=4f(2) = 2(8) - 9(4) + 12(2) = 16 - 36 + 24 = 4f(2)=2(8)−9(4)+12(2)=16−36+24=4

    3. 直接挑选：最大的是 9，最小的是 0。
    4. 【答案】 最大值为 9，最小值为 0。

【第 8 题】三次函数的驻点与极值点辨析 #
