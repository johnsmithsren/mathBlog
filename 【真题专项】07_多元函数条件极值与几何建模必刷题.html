【真题专项】07_多元函数条件极值（拉格朗日乘数法）与几何建模必刷题 #

题型定位：考研数学二解答题第 18 题或第 19 题（分值 10~12 分），考查多元函数无条件/条件极值的大题模板。
保分目标：稳拿 10 分满分（方程构造完全固定，按照“立函数 →\to→ 偏导为零 →\to→ 联立消元 →\to→ 判定最值”4步机械化拿满分）。

模块一：拉格朗日乘数法 4 步通关流水线（考场满分模板） #

求目标函数 f(x,y,z)f(x, y, z)f(x,y,z) 在约束条件 φ(x,y,z)=0\varphi(x, y, z) = 0φ(x,y,z)=0 下的极值：

Step 1：构造辅助函数（拉格朗日函数） #

L(x,y,z,λ)=f(x,y,z)+λφ(x,y,z)L(x, y, z, \lambda) = f(x, y, z) + \lambda \varphi(x, y, z)L(x,y,z,λ)=f(x,y,z)+λφ(x,y,z)

（若是两个约束条件 φ1=0,φ2=0\varphi_1 = 0, \varphi_2 = 0φ1​=0,φ2​=0，则设 L=f+λφ1+μφ2L = f + \lambda \varphi_1 + \mu \varphi_2L=f+λφ1​+μφ2​）。

Step 2：求各变量的一阶偏导数并令其为 0 #

列出联立方程组：

{Lx′=fx′+λφx′=0Ly′=fy′+λφy′=0Lz′=fz′+λφz′=0Lλ′=φ(x,y,z)=0\begin{cases} L'_x = f'_x + \lambda \varphi'_x = 0 \\ L'_y = f'_y + \lambda \varphi'_y = 0 \\ L'_z = f'_z + \lambda \varphi'_z = 0 \\ L'_\lambda = \varphi(x, y, z) = 0 \end{cases}⎩⎨⎧​Lx′​=fx′​+λφx′​=0Ly′​=fy′​+λφy′​=0Lz′​=fz′​+λφz′​=0Lλ′​=φ(x,y,z)=0​

Step 3：机械化联立消元技巧（关键避坑！） #

  • 技巧 1（比例法）：用前几个方程把 λ\lambdaλ 表达出来，或者两两相除把 λ\lambdaλ 约掉，建立自变量之间的比例关系（如 fx′φx′=fy′φy′\frac{f'_x}{\varphi'_x} = \frac{f'_y}{\varphi'_y}φx′​fx′​​=φy′​fy′​​）；
  • 技巧 2（对称法）：若变量在方程中具有轮换对称性，通常有 x=y=zx = y = zx=y=z；
  • 技巧 3（代回约束方程）：把得到的比例关系代入最后一个约束方程 φ(x,y,z)=0\varphi(x, y, z) = 0φ(x,y,z)=0，直接解出驻点坐标 (x0,y0,z0)(x_0, y_0, z_0)(x0​,y0​,z0​)。

Step 4：结合实际背景判定最值并写结论 #

由于考研中绝大部分是实际几何或物理应用题（如体积、造价、距离），在实际问题中最值必然存在：

  • 如果求出的驻点唯一，则该驻点对应的函数值必然就是最大值（或最小值）！
  • 考场规范答题套语：“由实际几何背景可知，该函数在定义域内必存在最大值（最小值），且驻点唯一，故当 x=x0,y=y0x=x_0, y=y_0x=x0​,y=y0​ 时取最大值（最小值）为 f(x0,y0)f(x_0, y_0)f(x0​,y0​)”。

【大题 3：空间点到平面的最短距离（二次函数代换）】 #

题目：在平面 x+2y−z=4x + 2y - z = 4x+2y−z=4 上求一点，使其到原点的距离最近，并求该最短距离。

【规范解答】

  1. 简化目标函数： 点 (x,y,z)(x, y, z)(x,y,z) 到原点距离 d=x2+y2+z2d = \sqrt{x^2 + y^2 + z^2}d=x2+y2+z2​ 最小，等价于距离平方 f(x,y,z)=x2+y2+z2f(x, y, z) = x^2 + y^2 + z^2f(x,y,z)=x2+y2+z2 最小。
  2. 构造辅助函数：

  1. 偏导联立：

{Lx′=2x+λ=0  ⟹  x=−λ2Ly′=2y+2λ=0  ⟹  y=−λLz′=2z−λ=0  ⟹  z=λ2\begin{cases} L'_x = 2x + \lambda = 0 \implies x = -\frac{\lambda}{2} \\ L'_y = 2y + 2\lambda = 0 \implies y = -\lambda \\ L'_z = 2z - \lambda = 0 \implies z = \frac{\lambda}{2} \end{cases}⎩⎨⎧​Lx′​=2x+λ=0⟹x=−2λ​Ly′​=2y+2λ=0⟹y=−λLz′​=2z−λ=0⟹z=2λ​​

所以：

x=23,y=43,z=−23x = \frac{2}{3}, \quad y = \frac{4}{3}, \quad z = -\frac{2}{3}x=32​,y=34​,z=−32​

  1. 求最短距离：
