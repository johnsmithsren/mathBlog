线性代数王牌模型：矩阵乘积为零 AC=OAC=OAC=O 与秩不等式夹逼秒杀题 #

一、题目原型（660 题 / 考研高频真题同款） #

【题目】
设 AAA 为 4×54 \times 54×5 矩阵，B,CB, CB,C 为 5×45 \times 45×4 矩阵，若 AB=EAB = EAB=E，AC=OAC = OAC=O，C≠OC \neq OC=O，则 r(C)=r(C) =r(C)=（____）。
(A) 111
(B) 222
(C) 333
(D) 444

【答案】：(A)

二、核心考点透析（考研线代 2 大灵魂定理） #

[!IMPORTANT]

定理 1：乘积为单位阵 AB=EAB = EAB=E 的“满秩锁定” #

  1. 因为 AAA 是 4×54 \times 54×5 矩阵，BBB 是 5×45 \times 45×4 矩阵，乘积 ABABAB 是 4×44 \times 44×4 的单位矩阵 E4E_4E4​。
  2. 由秩的性质：

4=r(E)=r(AB)≤min⁡{r(A),r(B)}4 = r(E) = r(AB) \le \min\{r(A), r(B)\}4=r(E)=r(AB)≤min{r(A),r(B)}

同时由于 AAA 只有 4 行，其秩 r(A)≤4r(A) \le 4r(A)≤4。 3. 由夹逼准则：

4≤r(A)≤4  ⟹  r(A)=44 \le r(A) \le 4 \implies \mathbf{r(A) = 4}4≤r(A)≤4⟹r(A)=4

（AAA 是行满秩矩阵）。

[!IMPORTANT]

定理 2：乘积为零阵 AC=OAC = OAC=O 的“解向量与秩不等式” #

当看到两个非零矩阵乘积为零 AC=OAC = OAC=O 时，考场有两种秒杀视角：

视角一（解空间视角——视频老师的解法，最通俗）：

  • 将 CCC 按列分块写成 C=(c1,c2,c3,c4)C = (\boldsymbol{c}_1, \boldsymbol{c}_2, \boldsymbol{c}_3, \boldsymbol{c}_4)C=(c1​,c2​,c3​,c4​)；
  • 则 AC=A(c1,c2,c3,c4)=(Ac1,Ac2,Ac3,Ac4)=(0,0,0,0)AC = A(\boldsymbol{c}_1, \boldsymbol{c}_2, \boldsymbol{c}_3, \boldsymbol{c}_4) = (A\boldsymbol{c}_1, A\boldsymbol{c}_2, A\boldsymbol{c}_3, A\boldsymbol{c}_4) = (\mathbf{0}, \mathbf{0}, \mathbf{0}, \mathbf{0})AC=A(c1​,c2​,c3​,c4​)=(Ac1​,Ac2​,Ac3​,Ac4​)=(0,0,0,0)；
  • 这说明：矩阵 CCC 的每一个列向量 ci\boldsymbol{c}_ici​ 都是齐次线性方程组 Ax=0A\boldsymbol{x} = \mathbf{0}Ax=0 的解！
  • 方程组 Ax=0A\boldsymbol{x} = \mathbf{0}Ax=0 中未知数个数 n=5n = 5n=5（AAA 的列数），其基础解系含有的向量个数为：

s=n−r(A)=5−4=1s = n - r(A) = 5 - 4 = \mathbf{1}s=n−r(A)=5−4=1

  • 因为所有的解向量都只能由基础解系线性表出，所以 CCC 的所有列向量最多只能张成 1 维子空间：

r(C)≤s=1r(C) \le s = 1r(C)≤s=1

视角二（西尔维斯特秩不等式——极速秒杀）：

  • 若 Am×nCn×k=OA_{m \times n} C_{n \times k} = OAm×n​Cn×k​=O，必有西尔维斯特不等式：

r(A)+r(C)≤n(n 为 A 的列数 / C 的行数)r(A) + r(C) \le n \quad (n \text{ 为 } A \text{ 的列数 / } C \text{ 的行数})r(A)+r(C)≤n(n 为 A 的列数 / C 的行数)

  • 代入本题数据：

4+r(C)≤5  ⟹  r(C)≤14 + r(C) \le 5 \implies r(C) \le 14+r(C)≤5⟹r(C)≤1

三、规范详细解答过程 #

  1. 第一步（锁定 r(A)r(A)r(A)）： 由 AB=E4AB = E_4AB=E4​，根据乘积的秩不大于各因子的秩：

4=r(E)=r(AB)≤r(A)≤4  ⟹  r(A)=44 = r(E) = r(AB) \le r(A) \le 4 \implies r(A) = 44=r(E)=r(AB)≤r(A)≤4⟹r(A)=4

  1. 第二步（利用 AC=OAC=OAC=O 判定上界）： 由 AC=OAC = OAC=O，根据西尔维斯特秩不等式：

r(A)+r(C)≤5  ⟹  4+r(C)≤5  ⟹  r(C)≤1r(A) + r(C) \le 5 \implies 4 + r(C) \le 5 \implies r(C) \le 1r(A)+r(C)≤5⟹4+r(C)≤5⟹r(C)≤1

  1. 第三步（结合已知非零判定下界）： 题目明确给出 C≠OC \neq OC=O（CCC 是非零矩阵），因此：

r(C)≥1r(C) \ge 1r(C)≥1

  1. 第四步（两面夹逼得出答案）： 综合 1≤r(C)≤11 \le r(C) \le 11≤r(C)≤1，必有：

r(C)=1r(C) = 1r(C)=1

故选 (A)。

四、举一反三（考场同款变形与秒杀口诀） #

[!TIP] 做题口诀：

  • 看到 AC=OAC = OAC=O   ⟹  \implies⟹ CCC 的每一列都是 Ax=0Ax=0Ax=0 的解，或者直接套 r(A)+r(C)≤nr(A) + r(C) \le nr(A)+r(C)≤n；
  • 只要 CCC 非零且 n−r(A)=1n - r(A) = 1n−r(A)=1，r(C)r(C)r(C) 闭着眼睛直接选 1！
