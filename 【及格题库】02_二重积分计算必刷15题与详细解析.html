题 1：交换积分次序（无法直接求原函数型） #

【题目】
计算二重积分：

【规范解题步骤】

  1. 确定积分区域 DDD： 由原积分上下限可知，区域为：

D={(x,y)∣y≤x≤1, 0≤y≤1}D = \{ (x, y) \mid y \le x \le 1, \ 0 \le y \le 1 \}D={(x,y)∣y≤x≤1, 0≤y≤1}

D={(x,y)∣0≤x≤1, 0≤y≤x}D = \{ (x, y) \mid 0 \le x \le 1, \ 0 \le y \le x \}D={(x,y)∣0≤x≤1, 0≤y≤x}

  1. 故：
