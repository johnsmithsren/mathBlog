向量组线性相关性：个数与维数两大口诀精讲 #

来源：880 题线代选择题（考研数学小侯七侯掌门讲解）整理 关键词：线性相关、线性无关、零解、部分组与整体组、接长（延伸）向量组

一、基础概念回顾 #

1. 线性相关 / 线性无关 #

对向量组 α1,α2,…,αs\alpha_1, \alpha_2, \dots, \alpha_sα1​,α2​,…,αs​，考察

k1α1+k2α2+⋯+ksαs=0k_1\alpha_1 + k_2\alpha_2 + \cdots + k_s\alpha_s = 0k1​α1​+k2​α2​+⋯+ks​αs​=0

情况 定义 直观含义
线性相关 存在不全为 0 的 kik_iki​ 使上式成立 至少有一个向量能被其余向量线性表示（有“多余”向量）
线性无关 只有 k1=⋯=ks=0k_1 = \cdots = k_s = 0k1​=⋯=ks​=0 时才成立 任何一个向量都不能被其余向量表示

2. 零解与非零解 #

  • 零解：所有未知数全为 0，即 x=0x = 0x=0。
  • 非零解：未知数中至少有一个不为 0。
  • 齐次方程组 Ax=0Ax = 0Ax=0 必有零解，关键问题是“除了零解还有没有别的解”。
  • 非齐次方程组 Ax=b (b≠0)Ax = b\ (b \neq 0)Ax=b (b=0) 的解一定不是零解（代入得 0=b0 = b0=b，矛盾）。

[!IMPORTANT] 把 k1,…,ksk_1, \dots, k_sk1​,…,ks​ 看成未知数，k1α1+⋯+ksαs=0k_1\alpha_1 + \cdots + k_s\alpha_s = 0k1​α1​+⋯+ks​αs​=0 就是齐次方程组 Ak=0Ak = 0Ak=0，其中 A=(α1,…,αs)A = (\alpha_1, \dots, \alpha_s)A=(α1​,…,αs​)：

  • 只有零解   ⟺  \iff⟺ 线性无关
  • 有非零解   ⟺  \iff⟺ 线性相关

3. 行列式与方程组解的关系（AAA 为 nnn 阶方阵） #

∣A∣≠0\lvert A\rvert \neq 0∣A∣=0 ∣A∣=0\lvert A\rvert = 0∣A∣=0
齐次 Ax=0Ax = 0Ax=0 只有零解 有非零解（无穷多解）
非齐次 Ax=bAx = bAx=b 唯一解（克拉默法则 xi=Di/Dx_i = D_i / Dxi​=Di​/D） 无解或无穷多解（需比较 r(A)r(A)r(A) 与 r(A∣b)r(A \mid b)r(A∣b)）

二、口诀一（按“个数”）：大无关 ⇒ 小无关；小相关 ⇒ 大相关 #

这里的“大 / 小”指的是向量个数：整体组是“大”，从中取出的部分组是“小”。

  • 整体无关 ⇒ 部分无关（大无关 ⇒ 小无关）
  • 部分相关 ⇒ 整体相关（小相关 ⇒ 大相关），两条互为逆否命题

为什么成立 #

若部分组 α1,α2\alpha_1, \alpha_2α1​,α2​ 相关，就存在不全为 0 的 k1,k2k_1, k_2k1​,k2​ 使 k1α1+k2α2=0k_1\alpha_1 + k_2\alpha_2 = 0k1​α1​+k2​α2​=0。 把其余向量的系数全取 0：

k1α1+k2α2+0⋅α3+⋯=0k_1\alpha_1 + k_2\alpha_2 + 0\cdot\alpha_3 + \cdots = 0k1​α1​+k2​α2​+0⋅α3​+⋯=0

系数仍然不全为 0，所以整体组也相关。

反方向不成立（反例） #

e1=(1,0)T, e2=(0,1)Te_1 = (1,0)^T,\ e_2 = (0,1)^Te1​=(1,0)T, e2​=(0,1)T 线性无关，再加一个 e1+e2e_1 + e_2e1​+e2​ 就线性相关了。所以小无关 ⇏ 大无关。

直观记法：向量越多，越容易“挤”出多余的向量，也就越容易相关。

配套重要定理 #

[!IMPORTANT] 若 α1,…,αs\alpha_1, \dots, \alpha_sα1​,…,αs​ 线性无关，而 α1,…,αs,β\alpha_1, \dots, \alpha_s, \betaα1​,…,αs​,β 线性相关，则 β\betaβ 可由 α1,…,αs\alpha_1, \dots, \alpha_sα1​,…,αs​ 线性表示，且表示法唯一。

逆否形式：若 α1,…,αs\alpha_1, \dots, \alpha_sα1​,…,αs​ 无关，且 β\betaβ 不能由它们表示，则 α1,…,αs,β\alpha_1, \dots, \alpha_s, \betaα1​,…,αs​,β 线性无关。

例题（880 题） #

【题目】 设向量组 α1,α2,α3\alpha_1, \alpha_2, \alpha_3α1​,α2​,α3​ 线性无关，向量 β1\beta_1β1​ 可由 α1,α2,α3\alpha_1, \alpha_2, \alpha_3α1​,α2​,α3​ 线性表示，向量 β2\beta_2β2​ 不能由 α1,α2,α3\alpha_1, \alpha_2, \alpha_3α1​,α2​,α3​ 线性表示，则必有（ ）

(A) α1,α2,β1\alpha_1, \alpha_2, \beta_1α1​,α2​,β1​ 线性无关 (B) α1,α2,β2\alpha_1, \alpha_2, \beta_2α1​,α2​,β2​ 线性无关 (C) α2,α3,β1,β2\alpha_2, \alpha_3, \beta_1, \beta_2α2​,α3​,β1​,β2​ 线性相关 (D) α1,α2,α3,β1+β2\alpha_1, \alpha_2, \alpha_3, \beta_1 + \beta_2α1​,α2​,α3​,β1​+β2​ 线性相关

【答案】 (B)

【解析】

  • (B) 正确：α1,α2,α3\alpha_1, \alpha_2, \alpha_3α1​,α2​,α3​ 无关，β2\beta_2β2​ 不能由它们表示，由配套定理知 α1,α2,α3,β2\alpha_1, \alpha_2, \alpha_3, \beta_2α1​,α2​,α3​,β2​ 线性无关（大无关）。 α1,α2,β2\alpha_1, \alpha_2, \beta_2α1​,α2​,β2​ 是它的部分组，根据大无关 ⇒ 小无关，所以 α1,α2,β2\alpha_1, \alpha_2, \beta_2α1​,α2​,β2​ 线性无关。
  • (A) 错误：取 β1=α1\beta_1 = \alpha_1β1​=α1​，则 α1,α2,β1\alpha_1, \alpha_2, \beta_1α1​,α2​,β1​ 中有两个向量相同，线性相关。
  • (C) 错误：同样取 β1=α1\beta_1 = \alpha_1β1​=α1​，则 α2,α3,α1,β2\alpha_2, \alpha_3, \alpha_1, \beta_2α2​,α3​,α1​,β2​ 就是上面那组线性无关的向量，并不相关。
  • (D) 错误：若 β1+β2\beta_1 + \beta_2β1​+β2​ 能由 αi\alpha_iαi​ 表示，则 β2=(β1+β2)−β1\beta_2 = (\beta_1 + \beta_2) - \beta_1β2​=(β1​+β2​)−β1​ 也能由 αi\alpha_iαi​ 表示，矛盾。 所以 β1+β2\beta_1 + \beta_2β1​+β2​ 不能由 αi\alpha_iαi​ 表示，α1,α2,α3,β1+β2\alpha_1, \alpha_2, \alpha_3, \beta_1 + \beta_2α1​,α2​,α3​,β1​+β2​ 线性无关。

三、口诀二（按“维数”）：低维无关 ⇒ 高维无关；高维相关 ⇒ 低维相关 #

这里比较的是向量的维数（分量个数）。在每个向量后面添加分量得到的新向量组，叫做接长（延伸）向量组。

  • 低维无关 ⇒ 高维无关（原组无关，接长后仍无关）
  • 高维相关 ⇒ 低维相关（接长后相关，原组必相关），两条互为逆否命题

为什么成立：多一个分量 = 多一个方程 #

设 αi=(ai1,ai2,ai3)\alpha_i = (a_{i1}, a_{i2}, a_{i3})αi​=(ai1​,ai2​,ai3​)，接长为 βi=(ai1,ai2,ai3,ai4)\beta_i = (a_{i1}, a_{i2}, a_{i3}, a_{i4})βi​=(ai1​,ai2​,ai3​,ai4​)。

k1α1+k2α2+k3α3=0k_1\alpha_1 + k_2\alpha_2 + k_3\alpha_3 = 0k1​α1​+k2​α2​+k3​α3​=0 按分量展开是 3 个方程； k1β1+k2β2+k3β3=0k_1\beta_1 + k_2\beta_2 + k_3\beta_3 = 0k1​β1​+k2​β2​+k3​β3​=0 是这 3 个方程再加上第 4 个方程：

a14k1+a24k2+a34k3=0a_{14}k_1 + a_{24}k_2 + a_{34}k_3 = 0a14​k1​+a24​k2​+a34​k3​=0

方程越多、约束越强，解只会更少：

{(II) 的解}⊆{(I) 的解}\{\text{(II) 的解}\} \subseteq \{\text{(I) 的解}\}{(II) 的解}⊆{(I) 的解}

  • (Ⅰ) 只有零解 ⇒ (Ⅱ) 也只有零解，即低维无关 ⇒ 高维无关
  • (Ⅱ) 有非零解 ⇒ 这个解也满足 (Ⅰ)，即高维相关 ⇒ 低维相关

反方向不成立（反例） #

  • (Ⅰ)：α1=(1,0,0), α2=(1,0,0), α3=(0,1,0)\alpha_1 = (1,0,0),\ \alpha_2 = (1,0,0),\ \alpha_3 = (0,1,0)α1​=(1,0,0), α2​=(1,0,0), α3​=(0,1,0)，因为 α1=α2\alpha_1 = \alpha_2α1​=α2​，所以相关
  • (Ⅱ)：β1=(1,0,0,0), β2=(1,0,0,1), β3=(0,1,0,0)\beta_1 = (1,0,0,0),\ \beta_2 = (1,0,0,1),\ \beta_3 = (0,1,0,0)β1​=(1,0,0,0), β2​=(1,0,0,1), β3​=(0,1,0,0)，接长后无关

所以低维相关 ⇏ 高维相关。

直观记法：加分量 = 增加区分度。原本能区分开的（无关）加了分量仍能区分开；原本区分不开的（相关）加了分量以后可能就区分开了。

例题（880 题） #

【题目】 设向量组 (Ⅰ)：α1=(a11,a12,a13), α2=(a21,a22,a23), α3=(a31,a32,a33)\alpha_1 = (a_{11}, a_{12}, a_{13}),\ \alpha_2 = (a_{21}, a_{22}, a_{23}),\ \alpha_3 = (a_{31}, a_{32}, a_{33})α1​=(a11​,a12​,a13​), α2​=(a21​,a22​,a23​), α3​=(a31​,a32​,a33​)； 向量组 (Ⅱ)：β1=(a11,a12,a13,a14), β2=(a21,a22,a23,a24), β3=(a31,a32,a33,a34)\beta_1 = (a_{11}, a_{12}, a_{13}, a_{14}),\ \beta_2 = (a_{21}, a_{22}, a_{23}, a_{24}),\ \beta_3 = (a_{31}, a_{32}, a_{33}, a_{34})β1​=(a11​,a12​,a13​,a14​), β2​=(a21​,a22​,a23​,a24​), β3​=(a31​,a32​,a33​,a34​)，则正确的命题是（ ）

(A) (Ⅰ) 相关 ⇒ (Ⅱ) 相关 (B) (Ⅰ) 无关 ⇒ (Ⅱ) 无关 (C) (Ⅱ) 无关 ⇒ (Ⅰ) 无关 (D) (Ⅱ) 相关 ⇒ (Ⅰ) 无关

【答案】 (B)

【解析】 (Ⅱ) 是 (Ⅰ) 的接长向量组。由低维无关 ⇒ 高维无关知 (B) 正确。 (A)、(C) 方向反了，上面的反例可以否定；(D) 由高维相关 ⇒ 低维相关，推出的是 (Ⅰ) 相关，不是无关。

四、两大口诀对比速记 #

口诀 比较对象 无关的传递方向 相关的传递方向
口诀一 个数（整体组 vs 部分组） 大（多）无关 ⇒ 小（少）无关 小（少）相关 ⇒ 大（多）相关
口诀二 维数（接长组 vs 原组） 低维无关 ⇒ 高维无关 高维相关 ⇒ 低维相关

[!WARNING] 两条口诀里“无关”传递的方向相反，考场上很容易混淆：

  • 个数变多，向量更容易相关，所以无关只能往少的方向传；
  • 维数变高，向量更容易无关，所以无关可以往高的方向传。

一句话：加向量，无关可能变相关；加分量，相关可能变无关。
